## 新增需求

### 需求：acme.sh 安装检测

系统应自动检测 acme.sh 是否已安装，并提供安装引导。

#### 场景：检测 acme.sh 已安装
- **当** 已认证用户发送 GET /api/ssl/status
- **则** 系统返回 acme.sh 安装状态、版本号

#### 场景：安装 acme.sh
- **当** 已认证用户发送 POST /api/ssl/install
- **则** 系统执行 acme.sh 安装脚本并返回安装结果

### 需求：SSL 证书申请

系统应支持通过 acme.sh 申请 Let's Encrypt SSL 证书。

#### 场景：成功申请证书
- **当** 已认证用户发送 POST /api/ssl/issue，携带域名
- **则** 系统调用 acme.sh --issue，申请成功后将证书信息返回

#### 场景：申请证书失败
- **当** acme.sh 申请证书失败
- **则** 系统返回 acme.sh 的错误输出信息

### 需求：证书列表查看

系统应展示所有已申请的 SSL 证书。

#### 场景：获取证书列表
- **当** 已认证用户发送 GET /api/ssl/certs
- **则** 系统从 ~/.acme.sh/ 目录解析并返回证书列表（域名、到期时间、签发日期）

### 需求：证书续期

系统应支持手动续期 SSL 证书，续期后自动重载 Nginx。

#### 场景：成功续期证书
- **当** 已认证用户发送 POST /api/ssl/renew/:domain
- **则** 系统执行 acme.sh --renew，成功后 reload nginx

### 需求：证书全部续期

系统应支持一键续期所有已签发证书。

#### 场景：成功续期全部证书
- **当** 已认证用户发送 POST /api/ssl/renew-all
- **则** 系统调用 acme.sh --renew-all，续期完成后 reload nginx，返回续期结果

### 需求：证书删除

系统应支持从 acme.sh 中删除指定证书。

#### 场景：成功删除证书
- **当** 已认证用户发送 DELETE /api/ssl/cert/:domain
- **则** 系统调用 acme.sh --remove -d <domain>，清理 ~/.acme.sh 中的对应目录，返回成功

#### 场景：删除不存在的证书
- **当** 请求删除一个不存在的证书
- **则** 系统返回 404 错误

### 需求：SSL 管理页面 UI

系统应在 /#/ssl 提供 SSL 证书管理页面。

#### 场景：查看证书列表
- **当** 已认证用户导航到 /ssl
- **则** 页面显示证书列表（域名、到期时间、签发日期）和 acme.sh 安装状态

#### 场景：申请证书
- **当** 用户在证书页面输入域名并点击申请
- **则** 系统调用申请接口，显示申请进度和结果

#### 场景：手动续期
- **当** 用户点击证书的续期按钮
- **则** 系统执行续期并显示结果

#### 场景：全部续期
- **当** 用户点击"全部续期"按钮
- **则** 系统执行全部续期，显示进度和结果

#### 场景：删除证书
- **当** 用户点击证书行的"删除"按钮并确认
- **则** 系统删除该证书，列表刷新
