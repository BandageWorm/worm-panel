## 新增需求

### 需求：3X-UI 运行状态检测

系统应自动检测 3X-UI 是否安装及运行状态。

#### 场景：检测 3X-UI 状态
- **当** 已认证用户发送 GET /api/xui/status
- **则** 系统检测 systemctl status x-ui，返回安装状态、运行状态、版本、端口

#### 场景：获取详细信息
- **当** 已认证用户发送 GET /api/xui/info
- **则** 系统返回详细信息（安装路径、CPU、内存、运行时间）

#### 场景：3X-UI 未安装
- **当** 系统检测到 3X-UI 未安装
- **则** 返回未安装状态，提示用户

### 需求：3X-UI Nginx 反代管理

系统应为 3X-UI 配置 Nginx 反代入口。

#### 场景：配置反代入口
- **当** 已认证用户发送 POST /api/xui/proxy，携带域名
- **则** 系统生成 Nginx 反代配置，将域名指向 3X-UI 管理端口

#### 场景：获取反代入口
- **当** 已认证用户发送 GET /api/xui/proxy
- **则** 系统返回已配置的反代入口信息（URL）

#### 场景：移除反代入口
- **当** 已认证用户发送 DELETE /api/xui/proxy
- **则** 系统删除对应的 Nginx 反代配置并 reload

### 需求：3X-UI 管理页面 UI

系统应在 /#/xui 提供 3X-UI 管理页面。

#### 场景：查看 3X-UI 状态
- **当** 已认证用户导航到 /xui
- **则** 页面显示运行状态卡片（安装状态、版本、端口）

#### 场景：配置反代
- **当** 用户输入子域名并提交
- **则** 系统配置 Nginx 反代，页面显示入口链接

#### 场景：取消反代
- **当** 用户点击取消反代按钮并确认
- **则** 系统移除反代配置
