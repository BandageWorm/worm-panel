## Purpose

在面板中提供服务器文件系统的浏览与管理能力，支持目录导航、文件上传/下载/删除、新建目录以及文本文件的在线编辑。

## Requirements

### Requirement: 目录内容浏览

系统应支持浏览指定目录的文件和子目录列表。

#### Scenario: 列出目录内容
- **当** 已认证用户发送 GET /api/files，携带 path 参数（如 `/root` 或 `/var/www`）
- **则** 系统返回该目录下的文件和子目录列表，每项包含名称、类型（file/dir）、大小、修改时间、权限

#### Scenario: 路径不存在
- **当** 已认证用户发送 GET /api/files，path 指向不存在的目录
- **则** 系统返回 404 错误

#### Scenario: 路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### Requirement: 文件下载

系统应支持通过 API 下载指定文件。

#### Scenario: 下载文件
- **当** 已认证用户发送 GET /api/files/download，携带 path 参数指向一个文件
- **则** 系统以 application/octet-stream 流式返回文件内容

#### Scenario: 下载目录
- **当** path 指向一个目录
- **则** 系统返回错误，不支持目录下载

### Requirement: 文件上传

系统应支持通过 multipart/form-data 上传文件到指定目录。

#### Scenario: 成功上传文件
- **当** 已认证用户发送 POST /api/files/upload，携带目标 path 目录和 file 字段的文件数据
- **则** 系统将文件保存到目标目录，返回文件信息

#### Scenario: 上传到不存在的目录
- **当** path 指向不存在的目录
- **则** 系统返回错误

### Requirement: 上传文件名净化与路径逃逸防护

系统处理文件上传时 MUST 对上传文件名做净化：MUST 去除其中的目录部分，仅保留基础文件名；MUST 拒绝空文件名、`.`、`..` 以及净化后为空的名字。写入前系统 SHALL 校验最终绝对路径仍位于目标目录之内，否则 MUST 拒绝该上传。

#### Scenario: 文件名包含路径穿越片段

- **WHEN** 上传请求携带的文件名为 `../../etc/passwd` 或 `..%2F..%2Fetc%2Fpasswd`
- **THEN** 系统拒绝该上传并返回校验错误，不写入任何文件

#### Scenario: 文件名包含目录前缀

- **WHEN** 上传请求携带的文件名为 `sub/dir/a.txt`
- **THEN** 系统仅保留 `a.txt` 作为文件名保存到目标目录

#### Scenario: 文件名为空或为点

- **WHEN** 上传请求携带的文件名为空、`.` 或 `..`
- **THEN** 系统拒绝该上传并返回校验错误

#### Scenario: 目标目录不存在

- **WHEN** 上传请求指定的目标目录不存在
- **THEN** 系统返回错误，不创建文件

### Requirement: 文件删除

系统应支持删除文件或空目录。

#### Scenario: 删除文件
- **当** 已认证用户发送 DELETE /api/files，携带 path 指向一个文件
- **则** 系统删除该文件并返回成功

#### Scenario: 删除非空目录
- **当** path 指向一个非空目录
- **则** 系统返回错误，提示目录不为空

### Requirement: 新建目录

系统应支持在指定路径下创建新目录。

#### Scenario: 成功创建目录
- **当** 已认证用户发送 POST /api/files/mkdir，携带 path 参数
- **则** 系统创建该目录并返回成功

#### Scenario: 目录已存在
- **当** path 已存在
- **则** 系统返回错误

### Requirement: 文件浏览页面 UI

系统应在 /#/files 提供文件管理页面。

#### Scenario: 查看文件列表
- **当** 已认证用户导航到 /files
- **则** 页面显示文件列表表格，包含文件名、大小、类型、修改时间列，支持面包屑导航

#### Scenario: 进入子目录
- **当** 用户双击一个目录行
- **则** 页面进入该目录，刷新文件列表，面包屑更新

#### Scenario: 返回上级目录
- **当** 用户点击面包屑中的上级目录
- **则** 页面导航到对应目录

#### Scenario: 列头排序
- **当** 用户点击表格列头（名称/大小/修改时间）的排序按钮
- **则** 当前目录的文件列表按该列升序排列，再次点击切换为降序，目录始终排在文件前面

#### Scenario: 复制当前路径
- **当** 用户点击面包屑旁的复制按钮
- **则** 当前完整路径复制到剪贴板，显示复制成功提示

#### Scenario: 切换路径输入模式
- **当** 用户点击面包屑旁的编辑路径按钮
- **则** 面包屑切换为文本输入框，预填当前路径，支持手动修改

#### Scenario: 通过路径输入框导航
- **当** 用户在路径输入框中输入路径后按回车
- **则** 系统验证路径，若有效则导航到该目录并切回面包屑模式；若无效则提示路径不存在

#### Scenario: 双击文件打开编辑
- **当** 用户双击一个可编辑文件的行
- **则** 弹出编辑器弹窗，行为同点击"编辑"按钮

#### Scenario: 上传文件
- **当** 用户点击上传按钮，选择文件并确认
- **则** 文件上传到当前目录，列表刷新

#### Scenario: 下载文件
- **当** 用户点击文件行的下载按钮
- **则** 浏览器触发文件下载

#### Scenario: 删除文件
- **当** 用户点击文件行的删除按钮并确认
- **则** 系统删除文件，列表刷新

#### Scenario: 新建目录
- **当** 用户点击新建目录按钮，输入目录名并确认
- **则** 在当前目录下创建目录，列表刷新

### Requirement: 读取文件内容

系统应支持读取文本文件的内容并以 UTF-8 返回。

#### Scenario: 成功读取文本文件
- **当** 已认证用户发送 GET /api/files/read，path 参数指向一个存在的文本文件
- **则** 系统返回 200，JSON body 包含 `{ content: "<文件内容>" }`

#### Scenario: 文件不存在
- **当** path 指向不存在的文件
- **则** 系统返回 404 错误

#### Scenario: path 指向目录
- **当** path 指向一个目录
- **则** 系统返回 400 错误，提示"无法读取目录"

#### Scenario: 文件超过大小限制
- **当** 文件大小超过 1MB
- **则** 系统返回 413 错误，提示"文件过大无法编辑"

#### Scenario: 非 UTF-8 编码文件
- **当** 文件无法以 UTF-8 解码
- **则** 系统返回 400 错误，提示"不支持的文件编码"

#### Scenario: 路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### Requirement: 保存文件内容

系统应支持以 UTF-8 编码保存内容到指定文件。

#### Scenario: 成功保存文件
- **当** 已认证用户发送 PUT /api/files/write，body 为 `{ path: "<文件路径>", content: "<新内容>" }`
- **则** 系统将内容以 UTF-8 写入文件，返回 200 成功

#### Scenario: 父目录不存在
- **当** path 指向的父目录不存在
- **则** 系统返回 400 错误

#### Scenario: path 指向目录
- **当** path 指向一个目录
- **则** 系统返回 400 错误，提示"无法写入目录"

#### Scenario: 路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### Requirement: 文件编辑页面 UI

系统应在文件管理页面提供文本编辑器弹窗。

#### Scenario: 显示编辑按钮
- **当** 文件列表中的文件扩展名匹配可编辑类型白名单
- **则** 该文件行的操作列显示"编辑"按钮

#### Scenario: 隐藏编辑按钮
- **当** 文件扩展名不在白名单中，或该项是目录
- **则** 操作列不显示"编辑"按钮

#### Scenario: 打开编辑弹窗
- **当** 用户点击"编辑"按钮
- **则** 弹出编辑器对话框，标题显示"编辑文件: <路径>"，内容加载完成后显示在 CodeMirror 编辑器中，支持语法高亮

#### Scenario: 移动端编辑器字号
- **当** 在宽度 ≤768px 的设备上打开编辑器
- **则** CodeMirror 文本字号自动调整为 12px

#### Scenario: 取消编辑
- **当** 用户点击弹窗的"取消"按钮或关闭按钮
- **则** 弹窗关闭，不保存任何修改

#### Scenario: 保存文件
- **当** 用户修改内容后点击"保存"按钮
- **则** 系统调用保存 API，成功后关闭弹窗并显示成功提示，刷新文件列表

#### Scenario: 保存失败
- **当** 保存 API 返回错误
- **则** 弹窗保持打开，显示错误提示信息

#### Scenario: 编辑器加载失败
- **当** 读取文件内容 API 返回错误
- **则** 弹窗显示错误信息，编辑器不可用
