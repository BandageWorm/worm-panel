## 新增需求

### 需求：目录内容浏览

系统应支持浏览指定目录的文件和子目录列表。

#### 场景：列出目录内容
- **当** 已认证用户发送 GET /api/files，携带 path 参数（如 `/root` 或 `/var/www`）
- **则** 系统返回该目录下的文件和子目录列表，每项包含名称、类型（file/dir）、大小、修改时间、权限

#### 场景：路径不存在
- **当** 已认证用户发送 GET /api/files，path 指向不存在的目录
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### 需求：文件下载

系统应支持通过 API 下载指定文件。

#### 场景：下载文件
- **当** 已认证用户发送 GET /api/files/download，携带 path 参数指向一个文件
- **则** 系统以 application/octet-stream 流式返回文件内容

#### 场景：下载目录
- **当** path 指向一个目录
- **则** 系统返回错误，不支持目录下载

### 需求：文件上传

系统应支持通过 multipart/form-data 上传文件到指定目录。

#### 场景：成功上传文件
- **当** 已认证用户发送 POST /api/files/upload，携带目标 path 目录和 file 字段的文件数据
- **则** 系统将文件保存到目标目录，返回文件信息

#### 场景：上传到不存在的目录
- **当** path 指向不存在的目录
- **则** 系统返回错误

### 需求：文件删除

系统应支持删除文件或空目录。

#### 场景：删除文件
- **当** 已认证用户发送 DELETE /api/files，携带 path 指向一个文件
- **则** 系统删除该文件并返回成功

#### 场景：删除非空目录
- **当** path 指向一个非空目录
- **则** 系统返回错误，提示目录不为空

### 需求：新建目录

系统应支持在指定路径下创建新目录。

#### 场景：成功创建目录
- **当** 已认证用户发送 POST /api/files/mkdir，携带 path 参数
- **则** 系统创建该目录并返回成功

#### 场景：目录已存在
- **当** path 已存在
- **则** 系统返回错误

### 需求：文件浏览页面 UI

系统应在 /#/files 提供文件管理页面。

#### 场景：查看文件列表
- **当** 已认证用户导航到 /files
- **则** 页面显示文件列表表格，包含文件名、大小、类型、修改时间列，支持面包屑导航

#### 场景：进入子目录
- **当** 用户双击一个目录行
- **则** 页面进入该目录，刷新文件列表，面包屑更新

#### 场景：返回上级目录
- **当** 用户点击面包屑中的上级目录
- **则** 页面导航到对应目录

#### 场景：上传文件
- **当** 用户点击上传按钮，选择文件并确认
- **则** 文件上传到当前目录，列表刷新

#### 场景：下载文件
- **当** 用户点击文件行的下载按钮
- **则** 浏览器触发文件下载

#### 场景：删除文件
- **当** 用户点击文件行的删除按钮并确认
- **则** 系统删除文件，列表刷新

#### 场景：新建目录
- **当** 用户点击新建目录按钮，输入目录名并确认
- **则** 在当前目录下创建目录，列表刷新

### 需求：读取文件内容

系统应支持读取文本文件的内容并以 UTF-8 返回。

#### 场景：成功读取文本文件
- **当** 已认证用户发送 GET /api/files/read，path 参数指向一个存在的文本文件
- **则** 系统返回 200，JSON body 包含 `{ content: "<文件内容>" }`

#### 场景：文件不存在
- **当** path 指向不存在的文件
- **则** 系统返回 404 错误

#### 场景：path 指向目录
- **当** path 指向一个目录
- **则** 系统返回 400 错误，提示"无法读取目录"

#### 场景：文件超过大小限制
- **当** 文件大小超过 1MB
- **则** 系统返回 413 错误，提示"文件过大无法编辑"

#### 场景：非 UTF-8 编码文件
- **当** 文件无法以 UTF-8 解码
- **则** 系统返回 400 错误，提示"不支持的文件编码"

#### 场景：路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### 需求：保存文件内容

系统应支持以 UTF-8 编码保存内容到指定文件。

#### 场景：成功保存文件
- **当** 已认证用户发送 PUT /api/files/write，body 为 `{ path: "<文件路径>", content: "<新内容>" }`
- **则** 系统将内容以 UTF-8 写入文件，返回 200 成功

#### 场景：父目录不存在
- **当** path 指向的父目录不存在
- **则** 系统返回 400 错误

#### 场景：path 指向目录
- **当** path 指向一个目录
- **则** 系统返回 400 错误，提示"无法写入目录"

#### 场景：路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### 需求：文件编辑页面 UI

系统应在文件管理页面提供文本编辑器弹窗。

#### 场景：显示编辑按钮
- **当** 文件列表中的文件扩展名匹配可编辑类型白名单
- **则** 该文件行的操作列显示"编辑"按钮

#### 场景：隐藏编辑按钮
- **当** 文件扩展名不在白名单中，或该项是目录
- **则** 操作列不显示"编辑"按钮

#### 场景：打开编辑弹窗
- **当** 用户点击"编辑"按钮
- **则** 弹出编辑器对话框，标题显示"编辑文件: <路径>"，内容加载完成后显示在 CodeMirror 编辑器中，支持语法高亮

#### 场景：取消编辑
- **当** 用户点击弹窗的"取消"按钮或关闭按钮
- **则** 弹窗关闭，不保存任何修改

#### 场景：保存文件
- **当** 用户修改内容后点击"保存"按钮
- **则** 系统调用保存 API，成功后关闭弹窗并显示成功提示，刷新文件列表

#### 场景：保存失败
- **当** 保存 API 返回错误
- **则** 弹窗保持打开，显示错误提示信息

#### 场景：编辑器加载失败
- **当** 读取文件内容 API 返回错误
- **则** 弹窗显示错误信息，编辑器不可用
