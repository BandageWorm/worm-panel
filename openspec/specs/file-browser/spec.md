## 新增需求

### 需求：目录内容浏览

系统应支持浏览指定目录的文件和子目录列表。

#### 场景：列出目录内容
- **当** 已认证用户发送 GET /api/files，携带 path 参数（如 `/root` 或 `/var/www`）
- **则** 系统返回该目录下的文件和子目录列表，每项包含名称、类型（file/dir）、大小、修改时间、权限

#### 场景：路径不存在
- **当** 已认证用户发送 GET /api/files，path 指向不存在的目录
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** path 参数包含 `..` 或其他路径穿越字符
- **则** 系统拒绝请求并返回校验错误

### 需求：文件下载

系统应支持通过 API 下载指定文件。

#### 场景：下载文件
- **当** 已认证用户发送 GET /api/files/download，携带 path 参数指向一个文件
- **则** 系统以 application/octet-stream 流式返回文件内容

#### 场景：下载目录
- **当** path 指向一个目录
- **则** 系统返回错误，不支持目录下载

### 需求：文件上传

系统应支持通过 multipart/form-data 上传文件到指定目录。

#### 场景：成功上传文件
- **当** 已认证用户发送 POST /api/files/upload，携带目标 path 目录和 file 字段的文件数据
- **则** 系统将文件保存到目标目录，返回文件信息

#### 场景：上传到不存在的目录
- **当** path 指向不存在的目录
- **则** 系统返回错误

### 需求：文件删除

系统应支持删除文件或空目录。

#### 场景：删除文件
- **当** 已认证用户发送 DELETE /api/files，携带 path 指向一个文件
- **则** 系统删除该文件并返回成功

#### 场景：删除非空目录
- **当** path 指向一个非空目录
- **则** 系统返回错误，提示目录不为空

### 需求：新建目录

系统应支持在指定路径下创建新目录。

#### 场景：成功创建目录
- **当** 已认证用户发送 POST /api/files/mkdir，携带 path 参数
- **则** 系统创建该目录并返回成功

#### 场景：目录已存在
- **当** path 已存在
- **则** 系统返回错误

### 需求：文件浏览页面 UI

系统应在 /#/files 提供文件管理页面。

#### 场景：查看文件列表
- **当** 已认证用户导航到 /files
- **则** 页面显示文件列表表格，包含文件名、大小、类型、修改时间列，支持面包屑导航

#### 场景：进入子目录
- **当** 用户双击一个目录行
- **则** 页面进入该目录，刷新文件列表，面包屑更新

#### 场景：返回上级目录
- **当** 用户点击面包屑中的上级目录
- **则** 页面导航到对应目录

#### 场景：上传文件
- **当** 用户点击上传按钮，选择文件并确认
- **则** 文件上传到当前目录，列表刷新

#### 场景：下载文件
- **当** 用户点击文件行的下载按钮
- **则** 浏览器触发文件下载

#### 场景：删除文件
- **当** 用户点击文件行的删除按钮并确认
- **则** 系统删除文件，列表刷新

#### 场景：新建目录
- **当** 用户点击新建目录按钮，输入目录名并确认
- **则** 在当前目录下创建目录，列表刷新
