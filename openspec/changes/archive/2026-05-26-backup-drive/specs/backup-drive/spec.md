## ADDED Requirements

### Requirement: 备份盘文件列表

系统应展示备份盘根目录 `data/drive/` 下的文件和文件夹列表。

#### 场景：列出根目录内容
- **当** 已认证用户发送 GET /api/drive/list?path=/
- **则** 系统返回根目录下的文件和文件夹列表
- **则** 每个条目包含：名称、类型（文件/文件夹）、大小、修改时间

#### 场景：列出子目录内容
- **当** 已认证用户发送 GET /api/drive/list?path=/subdir
- **则** 系统返回指定子目录下的文件和文件夹列表

#### 场景：路径穿越防护
- **当** 请求路径包含 `../` 试图访问 drive 目录外
- **则** 系统返回 400 错误，拒绝访问

### Requirement: 文件上传

系统应支持通过拖拽或点击选择上传文件到备份盘指定目录。

#### 场景：上传成功
- **当** 已认证用户 POST /api/drive/upload 带上文件（multipart/form-data）和路径参数
- **则** 系统将文件保存到 `data/drive/` 对应路径
- **则** 系统触发后台同步到 WebDAV
- **则** 系统返回上传后的文件信息

#### 场景：上传到子目录
- **当** 用户在子目录中拖拽上传文件
- **则** 文件保存到对应的子目录下

#### 场景：单文件超过 500MB
- **当** 上传文件大小超过 500MB
- **则** 系统返回 413 错误，拒绝上传

#### 场景：文件重名
- **当** 上传的文件名与已存在的文件重名
- **则** 系统自动追加时间戳后缀避免覆盖

#### 场景：上传失败
- **当** 上传过程中发生磁盘错误或异常
- **则** 系统返回错误信息，不保存不完整文件

### Requirement: 文件下载

系统应支持从备份盘下载文件。

#### 场景：下载成功
- **当** 已认证用户 GET /api/drive/download?path=/file.zip
- **则** 系统以流式方式返回文件内容
- **则** 浏览器触发文件下载

#### 场景：下载不存在的文件
- **当** 请求下载的文件不存在
- **则** 系统返回 404 错误

#### 场景：下载文件夹
- **当** 请求的路径指向文件夹而非文件
- **则** 系统返回 400 错误，不支持文件夹下载

### Requirement: 文件删除

系统应支持删除备份盘中的文件或文件夹。

#### 场景：删除文件成功
- **当** 已认证用户 DELETE /api/drive/ 携带路径参数
- **则** 系统删除指定文件
- **则** 系统触发后台同步到 WebDAV
- **则** 返回删除成功状态

#### 场景：删除文件夹成功
- **当** 删除路径指向一个文件夹
- **则** 系统递归删除文件夹及其所有内容
- **则** 系统触发后台同步到 WebDAV

#### 场景：删除确认
- **当** 用户在 UI 点击删除按钮
- **则** 系统弹出确认对话框
- **则** 用户确认后才执行删除请求

### Requirement: 重命名

系统应支持重命名备份盘中的文件或文件夹。

#### 场景：重命名成功
- **当** 已认证用户 PUT /api/drive/rename 携带原路径和新名称
- **则** 系统执行重命名操作
- **则** 系统触发后台同步到 WebDAV
- **则** 返回重命名后的文件信息

#### 场景：重命名后名称已存在
- **当** 新名称与同一目录下已有文件/文件夹重名
- **则** 系统返回 409 冲突错误

### Requirement: 新建文件夹

系统应支持在备份盘中创建新文件夹。

#### 场景：新建文件夹成功
- **当** 已认证用户 POST /api/drive/mkdir 携带路径参数
- **则** 系统在指定路径下创建文件夹
- **则** 系统触发后台同步到 WebDAV
- **则** 返回文件夹信息

#### 场景：文件夹已存在
- **当** 指定路径的文件夹已存在
- **则** 系统返回 409 冲突错误

### Requirement: 备份盘页面 UI

系统应在 /#/sync 页面的云备份状态卡片和备份历史之间提供备份盘卡片。

#### 场景：显示备份盘卡片
- **当** 用户导航到 /sync 页面
- **则** 页面在状态卡片下方显示「备份盘」卡片
- **则** 卡片包含拖拽上传区域和文件列表

#### 场景：拖拽上传
- **当** 用户拖拽文件到上传区域
- **则** 区域高亮显示
- **则** 松开后文件自动上传到当前目录
- **则** 上传完成后刷新文件列表

#### 场景：点击上传
- **当** 用户点击上传区域
- **则** 系统弹出文件选择对话框，支持多文件选择
- **则** 选择后文件自动上传到当前目录
- **则** 上传完成后刷新文件列表

#### 场景：文件夹导航
- **当** 用户点击文件夹条目
- **则** 页面进入该文件夹，显示其内容
- **则** 面包屑导航更新，支持逐级返回

#### 场景：下载文件
- **当** 用户点击文件行的下载按钮
- **则** 浏览器下载该文件

#### 场景：删除文件
- **当** 用户点击文件行的删除按钮
- **则** 弹窗确认后执行删除
- **则** 删除后刷新文件列表

#### 场景：重命名文件
- **当** 用户点击文件行的重命名按钮（或双击文件名）
- **则** 文件名进入行内编辑模式
- **则** 用户确认后执行重命名
- **则** 重命名后刷新文件列表

#### 场景：新建文件夹按钮
- **当** 用户点击「新建文件夹」按钮
- **则** 弹出对话框输入文件夹名称
- **则** 确认后在当前目录创建文件夹
- **则** 创建后刷新文件列表

#### 场景：未连接 WebDAV 时
- **当** WebDAV 未连接或 rclone 未安装
- **则** 备份盘卡片正常显示
- **则** 上传/删除/重命名等本地操作正常可用
- **则** 页面提示「未连接到云端，文件仅保存在本地」

#### 场景：响应式布局
- **当** 在手机端访问 /sync 页面
- **则** 备份盘卡片全宽显示
- **则** 文件列表列数自适应减少
- **则** 操作按钮折叠或使用图标
