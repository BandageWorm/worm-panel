## ADDED Requirements

### Requirement: 重命名文件或目录
系统 SHALL 支持在同一目录内重命名文件或目录。

#### 场景：成功重命名
- **当** 已认证用户发送 POST /api/files/rename，body 为 `{ path: "<原路径>", newName: "<新名称>" }`
- **则** 系统将该文件或目录重命名为新名称（保持在同一父目录），返回成功

#### 场景：新名称为空或包含路径分隔符
- **当** newName 为空，或包含 `/` 等路径分隔符
- **则** 系统返回 400 错误，提示名称非法

#### 场景：目标名称已存在
- **当** 同目录下已存在同名文件或目录
- **则** 系统返回错误，提示目标已存在

#### 场景：原路径不存在
- **当** path 指向不存在的文件或目录
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** path 或 newName 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 移动文件或目录
系统 SHALL 支持将文件或目录移动到目标路径（可跨目录）。

#### 场景：成功移动到已存在目录
- **当** 已认证用户发送 POST /api/files/move，body 为 `{ src: "<源路径>", dest: "<已存在的目标目录>" }`
- **则** 系统将源移动为 `<目标目录>/<源名称>`，返回成功

#### 场景：目标目录不存在时自动创建
- **当** dest 指向一个不存在的目录路径
- **则** 系统自动创建该目录（含多级），再将源移入其中，返回成功

#### 场景：目标处已存在同名项
- **当** 目标目录下已存在与源同名的项
- **则** 系统返回错误，提示目标已存在，不覆盖

#### 场景：目标是已存在的文件
- **当** dest 指向一个已存在的文件（而非目录）
- **则** 系统返回错误，提示目标已存在且不是目录

#### 场景：源路径不存在
- **当** src 指向不存在的项
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** src 或 dest 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 复制文件或目录
系统 SHALL 支持将文件或目录复制到目标目录（目录递归复制），目标目录不存在时自动创建。

#### 场景：成功复制文件到目标目录
- **当** 已认证用户发送 POST /api/files/copy，body 为 `{ src: "<源文件>", dest: "<目标目录>" }`
- **则** 系统将该文件复制为 `<目标目录>/<源名称>`，返回成功

#### 场景：成功复制目录
- **当** src 指向一个目录
- **则** 系统递归复制该目录及其全部内容到目标目录下，返回成功

#### 场景：目标目录不存在时自动创建
- **当** dest 指向一个不存在的目录路径
- **则** 系统自动创建该目录（含多级），再将源复制到其中，返回成功

#### 场景：目标处已存在同名项时自动加后缀
- **当** 目标目录下已存在与源同名的项
- **则** 系统在文件名（扩展名前）追加 `_bak` 生成副本，再冲突则递增为 `_bak2`、`_bak3`…，返回最终副本路径

#### 场景：源路径不存在
- **当** src 指向不存在的项
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** src 或 dest 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 新建空文件
系统 SHALL 支持在指定路径创建一个空文件。

#### 场景：成功创建空文件
- **当** 已认证用户发送 POST /api/files/newfile，body 为 `{ path: "<文件路径>" }`
- **则** 系统在该路径创建一个空文件，返回成功

#### 场景：文件已存在
- **当** path 已存在
- **则** 系统返回错误，提示已存在，不覆盖

#### 场景：父目录不存在
- **当** path 的父目录不存在
- **则** 系统返回 400 错误

#### 场景：路径穿越防护
- **当** path 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 解压压缩包
系统 SHALL 支持将 `.tar`、`.tar.gz`/`.tgz`、`.zip` 压缩包解压到指定目录。

#### 场景：成功解压
- **当** 已认证用户发送 POST /api/files/extract，body 为 `{ path: "<压缩包路径>", dest: "<目标目录，可选，默认压缩包所在目录>" }`
- **则** 系统调用对应系统命令（tar/unzip）将内容解压到目标目录，返回成功

#### 场景：不支持的压缩格式
- **当** path 的扩展名不属于支持的压缩格式
- **则** 系统返回 400 错误，提示不支持的格式

#### 场景：所需解压命令缺失
- **当** 目标环境缺少对应的解压命令（如 unzip 未安装）
- **则** 系统返回错误，提示缺少所需命令

#### 场景：权限不足自动提权
- **当** 解压过程因权限不足失败
- **则** 系统自动以 sudo 重试该命令

#### 场景：路径穿越防护
- **当** path 或 dest 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 压缩文件或目录
系统 SHALL 支持将文件或目录打包为 `.tar.gz` 或 `.zip`。

#### 场景：成功压缩
- **当** 已认证用户发送 POST /api/files/compress，body 为 `{ path: "<源文件或目录>", format: "tar.gz|zip", dest: "<输出压缩包路径，可选>" }`
- **则** 系统调用对应系统命令生成压缩包，返回生成的压缩包路径

#### 场景：不支持的目标格式
- **当** format 不是 `tar.gz` 或 `zip`
- **则** 系统返回 400 错误

#### 场景：源路径不存在
- **当** path 指向不存在的项
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** path 或 dest 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 修改文件权限
系统 SHALL 支持修改文件或目录的权限位（chmod）。

#### 场景：成功修改权限
- **当** 已认证用户发送 POST /api/files/chmod，body 为 `{ path: "<路径>", mode: "755" }`（三位或四位八进制）
- **则** 系统将该路径的权限设置为指定值，返回成功

#### 场景：非法权限值
- **当** mode 不是合法的八进制权限字符串
- **则** 系统返回 400 错误

#### 场景：权限不足自动提权
- **当** 修改权限因当前进程权限不足失败
- **则** 系统自动以 sudo 重试

#### 场景：路径不存在
- **当** path 指向不存在的项
- **则** 系统返回 404 错误

#### 场景：路径穿越防护
- **当** path 触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 批量删除
系统 SHALL 支持一次删除多个文件或目录。

#### 场景：成功批量删除
- **当** 已认证用户发送 POST /api/files/batch-delete，body 为 `{ paths: ["<路径1>", "<路径2>", ...] }`
- **则** 系统逐项删除（目录递归删除），返回每项的成功或失败结果

#### 场景：部分失败
- **当** 其中部分路径删除失败（如不存在或无权限）
- **则** 系统继续处理剩余项，并在结果中标明每项的成败

#### 场景：路径穿越防护
- **当** 任一路径触发路径穿越，或落入敏感系统路径
- **则** 该项被拒绝并在结果中标为失败

### Requirement: 批量移动
系统 SHALL 支持将多个文件或目录移动到同一目标目录。

#### 场景：成功批量移动
- **当** 已认证用户发送 POST /api/files/batch-move，body 为 `{ paths: ["<路径1>", ...], dest: "<目标目录>" }`
- **则** 系统将每一项移动到目标目录下，返回每项的成功或失败结果

#### 场景：目标目录不存在时自动创建
- **当** dest 指向一个不存在的目录路径
- **则** 系统自动创建该目录后，将各项移入其中

#### 场景：目标是已存在的文件
- **当** dest 指向一个已存在的文件（而非目录）
- **则** 系统返回 400 错误

#### 场景：部分失败
- **当** 其中部分项移动失败（如目标已存在同名）
- **则** 系统继续处理剩余项，并在结果中标明每项的成败

### Requirement: 批量压缩
系统 SHALL 支持将多个（位于同一目录的）文件或目录打包为单个压缩包（tar.gz 或 zip）。

#### 场景：成功批量压缩
- **当** 已认证用户发送 POST /api/files/batch-compress，body 为 `{ paths: ["<路径1>", ...], format: "tar.gz|zip", dest: "<输出路径，可选>" }`
- **则** 系统将所有项打包为一个压缩包（默认 archive.tar.gz/archive.zip），返回压缩包路径

#### 场景：跨目录项
- **当** 选中的项不在同一目录下
- **则** 系统返回错误，提示批量压缩要求所有项位于同一目录

#### 场景：输出包已存在时自动加后缀
- **当** 默认输出包名已存在
- **则** 系统追加 `_bak` 后缀避免冲突，再冲突则递增

#### 场景：不支持的格式
- **当** format 不是 tar.gz 或 zip
- **则** 系统返回 400 错误

#### 场景：缺少所需命令
- **当** 目标环境缺少对应的压缩命令（如 zip 未安装）
- **则** 系统返回错误，提示缺少所需命令

#### 场景：路径穿越防护
- **当** 任一路径触发路径穿越，或落入敏感系统路径
- **则** 系统拒绝请求并返回校验错误

### Requirement: 文件管理页面扩展操作 UI
系统 SHALL 在文件管理页面提供重命名、移动、复制、压缩/解压、权限修改、新建文件、批量操作（删除/移动/压缩）、文件名搜索的入口。

#### 场景：重命名操作
- **当** 用户在文件行触发"重命名"，输入新名称并确认
- **则** 系统重命名该项，列表刷新

#### 场景：移动/复制操作
- **当** 用户在文件行触发"移动"或"复制"，选择或输入目标路径并确认
- **则** 系统执行移动或复制，列表刷新

#### 场景：新建文件
- **当** 用户点击"新建文件"，输入文件名并确认
- **则** 系统在当前目录创建空文件，列表刷新

#### 场景：解压操作
- **当** 用户在压缩包文件行触发"解压"并确认目标目录
- **则** 系统解压该压缩包，列表刷新

#### 场景：压缩操作
- **当** 用户在文件或目录行触发"压缩"，选择格式并确认
- **则** 系统生成压缩包，列表刷新

#### 场景：权限修改
- **当** 用户在文件行触发"权限"，修改权限值并确认
- **则** 系统 chmod 该项，列表刷新并显示新权限

#### 场景：文件名搜索
- **当** 用户在搜索框输入关键字
- **则** 当前目录列表仅显示名称包含该关键字的项

#### 场景：批量选择与操作
- **当** 用户勾选多行后点击批量删除、批量移动或批量压缩
- **则** 系统弹出二次确认（删除时），执行批量操作，列表刷新

#### 场景：批量压缩
- **当** 用户勾选多行后点击"批量压缩"，选择格式并确认
- **则** 系统将选中项打包为一个压缩包，列表刷新

### Requirement: 递归删除非空目录
系统 SHALL 支持删除非空目录（递归删除其全部内容），扩展原"仅支持删除空目录"的行为。

#### 场景：删除非空目录
- **当** 已认证用户发送 DELETE /api/files，path 指向一个非空目录，且请求指明递归删除（如 recursive=true）
- **则** 系统递归删除该目录及其全部内容并返回成功

#### 场景：未指明递归时删除非空目录
- **当** path 指向一个非空目录，但请求未指明递归删除
- **则** 系统返回错误，提示目录不为空，需确认递归删除

#### 场景：删除空目录保持兼容
- **当** path 指向一个空目录
- **则** 系统删除该目录并返回成功（与原行为一致）

#### 场景：前端二次确认
- **当** 用户在文件管理页面删除一个非空目录
- **则** 页面弹出二次确认，确认后携带递归标志调用删除，列表刷新

### Requirement: 文件权限列可编辑
系统 SHALL 在文件管理页面将权限列从只读展示扩展为可编辑入口（触发 chmod）。

#### 场景：展示权限并提供编辑入口
- **当** 已认证用户查看文件列表
- **则** 每行权限列显示当前八进制权限，并提供修改入口

#### 场景：修改权限后刷新展示
- **当** 用户通过权限编辑入口提交新的权限值
- **则** 系统 chmod 该项成功后，列表权限列显示更新后的值
